# Odair Siqueira Advocacia | Direito do Trabalho & Família em Colombo e Curitiba PR

Website institucional de alta performance desenvolvido para a **Odair Siqueira Advocacia** com Next.js 16 (App Router), React 19, Tailwind CSS v4, GSAP 3 e Lenis Smooth Scroll.

## 🚀 Tecnologias

- **Framework**: Next.js 16 (App Router)
- **UI**: React 19 + Tailwind CSS v4
- **Tipografia**: Cormorant Garamond + Inter
- **Paleta 60-30-10 & Harmonia**:
  - **Light Mode**: Marfim Acinzentado (`#F4F2EE`), Grafite Profundo (`#252525`), Cinza Prata (`#777777`) e Dourado Champagne (`#C9A24A`)
  - **Dark Mode**: Grafite Preto Profundo (`#171717`), Prata Claro (`#E2E2E2`), Cinza Metálico (`#9A9A9A`) e Dourado Champagne (`#C9A24A`)
- **Animações**: GSAP 3 + ScrollTrigger + @gsap/react + Lenis Smooth Scroll
- **Deploy**: Cloudflare Pages (`https://odairsiqueira.pages.dev`)
- **Conformidade Ética**: Provimento 205/2021 do CFOAB e Código de Ética e Disciplina da OAB (OAB/PR 91.151)

## 🛠️ Comandos

```bash
# Instalar dependências
npm install

# Rodar servidor local
npm run dev

# Gerar build estático para produção (pasta /out)
npm run build
```
